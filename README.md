# منصّة مستر محمد صبري — اللغة العربية 📖

منصّة تعليمية متكاملة لمادة **اللغة العربية** بتصميم عربي زخرفي فاخر (زمردي × ذهبي) مستوحى من التذهيب في المخطوطات العربية.

## ✦ المميزات

- **صفحة رئيسية مزخرفة**: هيرو بخلفية زخرفة إسلامية ذهبية، اسم المستر بخط الرقعة الذهبي المتلألئ، بسملة، وحِكم عربية في شريط متحرك.
- **الأخبار والإعلانات**: إدارة كاملة من لوحة المشرف وتظهر مباشرة في الرئيسية.
- **الدروس**: تصنيف حسب الصف الدراسي مع فلاتر وروابط للمحتوى.
- **نظام دخول المشرفين على مرحلتين** (كما هو موضح أدناه).
- تصميم متجاوب بالكامل (موبايل / تابلت / كمبيوتر) بالكامل باللغة العربية RTL.

## 🔐 الدخول

| المرحلة | المكان | البيانات |
|---------|--------|----------|
| 1 | زر «دخول» في الموقع | رقم تسجيل الدخول: `كلها خمسات` + كلمة السر |
| 2 | صفحة «دخول المشرفين» | البريد الإلكتروني + نفس كلمة السر |

> بيانات الدخول مُدارة من ملف `src/lib/admin-config.ts` ويمكن تعديلها من هناك بسهولة.

## ✦ التشغيل محليًا

```bash
# 1) تنصيب الحزم
bun install

# 2) إعداد قاعدة البيانات (SQLite)
#    أنشئ ملف .env فيه:
#    DATABASE_URL=file:/absolute/path/to/db/custom.db
bun run db:push

# 3) تشغيل خادم التطوير
bun run dev
```

افتح `http://localhost:3000`.

## ✦ التقنيات

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS 4** + مكونات **shadcn/ui**
- **Prisma** + **SQLite**
- **Framer Motion** للحركات، خطوط: Aref Ruqaa، Amiri، Reem Kufi، Cairo
